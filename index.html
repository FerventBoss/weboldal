Git vs. GitHub

A két nevet gyakran keverik, pedig két külön dologról van szó: az egyik a gépeden futó program, a másik egy online szolgáltatás, ami erre épül.

Szempont Git GitHub
Mi ez? Elosztott verziókezelő program Webes tárhely és együttműködési platform Git-repókhoz
Hol fut? A saját gépeden, internet nélkül is A felhőben, böngészőből és a Git parancsain keresztül érhető el
Mit tárol? A projekt teljes előzményét a .git mappában A repó távoli (remote) másolatát, amit a csapat közösen használ
Mire jó? Commitok, ágak, beolvasztás, korábbi állapot visszaállítása Megosztás, pull request, code review, issue-k, GitHub Pages
Eredete Linus Torvalds, 2005 2008 óta működik, 2018 óta a Microsoft tulajdona

A munkafolyamat

Egy módosítás négy helyen halad át, mire a csapattársad is látja. Az első három a saját gépeden van és internet nélkül is működik; a GitHub a közös, távoli repó.

Munkakönyvtár

A projektmappa a gépeden. Itt szerkeszted a fájlokat.

git add

Staging terület

A kijelölt változások, amelyek a következő commitba kerülnek.

git commit

Helyi repó

A commitok a .git mappában. Minden mentett állapot visszakereshető.

git push

GitHub

A közös távoli repó (origin). Innen kapja meg a munkádat a csapattársad.

git pull

Letölti a GitHubon lévő új commitokat, és beolvasztja őket a helyi ágadba és a munkakönyvtáradba (fetch + merge).

Ugyanez VS Code-ban

Parancs VS Code – Source Control nézet (Ctrl+Shift+G)
git add A fájl melletti + (Stage Changes), vagy a Changes sor melletti + az összes fájlhoz.
git commit Üzenet a szövegmezőbe, majd Commit.
git pull + git push Sync Changes gomb vagy az állapotsor szinkron ikonja: előbb lehúz, utána feltölt.
git switch -c Bal alsó sarokban az ág nevére kattintva: Create new branch…
git log --graph A Source Control nézet Graph része.
